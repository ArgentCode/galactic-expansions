# galactic-expansions

A sci-fi idle game!

How to do the game: 
1. run your virtual environment:
    py -m venv venv
    .\venv\Scripts\activate.ps1   
2. install packages 
    pip install -r .\requirements.txt
3. Run flask
    flask --app .\flaskoffun.py run
